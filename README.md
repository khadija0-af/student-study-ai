# StudyMate AI

Create a modern, polished and student-friendly web app called "StudyMate AI".

The app is an AI-powered study assistant for students.

Features:

Beautiful modern landing page

Hero section with the title "StudyMate AI"

Subtitle: "Your smart companion for learning, revision and study support."

Prominent "Ask StudyMate" button

Sections for Study Help, Notes & Resources, and Frequently Asked Questions

Clean dashboard-style interface

Responsive design for desktop and mobile

Navigation with Home, Study Help, Resources and About

Dedicated section where an AI chatbot can be embedded later

Professional UI suitable for a university project presentation

Design:

Use a slightly dark, elegant theme

Use dark navy/charcoal backgrounds with purple, lavender and subtle pink accents

Use good contrast so all text is clearly readable

Add smooth animations and hover effects, but keep the interface professional

Make the design modern and visually impressive without being overcrowded

Functionality:

Make sure ALL buttons and navigation links work properly

The "Ask StudyMate" button should navigate to the AI chatbot section

Navigation links should scroll to or open their respective sections

FAQ items should be interactive and expandable

Any forms or interactive elements should work correctly

Do not create buttons that appear clickable but have no functionality

Make sure there are no broken links or dead buttons

Ensure the complete app works smoothly before considering it finished

Make the application polished, intuitive, responsive and ready to demonstrate in an academic evaluation.
